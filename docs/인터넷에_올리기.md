# 인터넷에 올려서 폰으로 쓰기

PC를 켜두지 않아도, 회사 밖에서도 폰 브라우저로 쓸 수 있게 만드는 방법이다.

---

## 먼저 알아둘 것

### 설계 조건이 외부 서버로 나갑니다

계산은 남의 회사 서버에서 돌아간다. **사내 규정을 먼저 확인할 것.**
비밀번호는 걸리지만, 서버 운영사는 기술적으로 접근할 수 있다.

규정상 곤란하면 대안이 있다.

- 회사 내부망 서버에 같은 방식으로 올린다 (아래 파일 그대로 쓸 수 있다)
- PC에서 돌리고 폰은 같은 Wi-Fi로 접속한다 (앞서 이야기한 A안)

### 비밀번호는 필수다

비밀번호를 정하지 않으면 **계산 자체를 하지 않도록** 만들어 두었다.
설정을 빠뜨렸을 때 아무나 볼 수 있게 열리는 쪽이 더 위험하기 때문이다.

---

## Render 로 올리기 (추천)

무료 등급이 있고, GitHub 저장소를 연결하면 알아서 띄워준다.

### 1. 가입

[render.com](https://render.com) 에서 GitHub 계정으로 가입한다.

### 2. 저장소 연결

1. 대시보드에서 **New +** → **Web Service**
2. 이 저장소(`COMP-TEST-DATA`)를 고른다
3. 브랜치를 고른다
4. 나머지 설정은 `render.yaml` 을 읽어 자동으로 채워진다

직접 넣어야 하면 이렇게 넣는다.

| 항목 | 값 |
|------|-----|
| Runtime | Python 3 |
| Build Command | `pip install -r requirements-web.txt` |
| Start Command | `gunicorn turbochiller.wsgi:application --bind 0.0.0.0:$PORT --workers 2 --timeout 120` |
| Health Check Path | `/health` |

### 3. 비밀번호 설정 ← 빠뜨리면 안 된다

**Environment** 탭에서 환경변수를 추가한다.

| 이름 | 값 |
|------|-----|
| `TURBOCHILLER_PASSWORD` | 직접 정한 비밀번호 |
| `TURBOCHILLER_USER` | 아이디 (안 넣으면 `turbo`) |

> 비밀번호는 여기에만 넣는다. **코드나 파일에 적어 두면 안 된다.**
> GitHub 에 올라가면 저장소를 볼 수 있는 사람이 다 보게 된다.

### 4. 접속

배포가 끝나면 `https://이름.onrender.com` 같은 주소가 나온다.
폰 브라우저에서 열면 아이디·비밀번호를 묻는다.

**폰 홈 화면에 추가**해 두면 앱처럼 쓸 수 있다.
- 아이폰: 공유 → 홈 화면에 추가
- 안드로이드: 메뉴 → 홈 화면에 추가

## 무료 등급의 한계

Render 무료 등급은 **15분쯤 안 쓰면 잠든다.** 다시 열면 깨어나는 데
30초~1분쯤 걸린다. 첫 화면이 늦게 뜨는 건 고장이 아니다.

항상 빠르게 쓰려면 유료 등급으로 올리면 된다.

## 다른 곳에 올릴 때

`Dockerfile` 을 넣어 두었다. Docker 를 받는 곳이면 어디든 같은 방식으로 된다.

```bash
docker build -t turbochiller .
docker run -p 8000:8000 -e TURBOCHILLER_PASSWORD=비밀번호 turbochiller
```

Google Cloud Run, Fly.io, 회사 내부 서버 모두 이 방식으로 올릴 수 있다.

---

## 내 PC에서 먼저 시험해보기

올리기 전에 같은 환경으로 돌려볼 수 있다.

```bash
pip install -r requirements-web.txt
TURBOCHILLER_PASSWORD=시험용비번 python -m turbochiller.wsgi
```

윈도우 명령 프롬프트에서는 이렇게 한다.

```cmd
set TURBOCHILLER_PASSWORD=시험용비번
python -m turbochiller.wsgi
```

브라우저에서 `http://127.0.0.1:8000` 을 열면 아이디·비밀번호를 묻는다.

## 올린 화면과 내 PC 화면의 차이

| | 내 PC (`실행_윈도우.bat`) | 인터넷에 올린 것 |
|---|---|---|
| 비밀번호 | 없음 | **필수** |
| '종료' 버튼 | 있음 | **없음** (누구든 서버를 내릴 수 있으면 안 된다) |
| 서버 | 파이썬 내장 | gunicorn (여러 명이 붙어도 됨) |
| POST 요청 | — | 막음 |
| 캐시 | — | 끔 (`no-store`) |

이 차이는 `tests/test_wsgi.py` 가 검사한다.

## 폰 화면

폰에서는 **결과가 먼저 나오고 입력칸이 아래로** 간다.
입력칸이 20개라 그게 먼저 나오면 결과까지 한참 스크롤해야 하기 때문이다.

오른쪽 아래 **'입력값 고치기 ↓'** 단추를 누르면 입력칸으로 바로 내려간다.
표가 화면보다 넓으면 그 표만 옆으로 밀린다 (페이지 전체가 밀리지 않는다).
