# 엑셀 계산서 — 애드인 없이 혼자 도는 판

REFPROP·CoolProp 애드인 없이, **엑셀 파일 하나만으로** 사이클이 계산된다.
물성표를 시트에 심어 두고 보간으로 꺼내 쓰기 때문이다.

```bash
python -m excel.make_all          # excel/출력/ 에 냉매별 파일이 생긴다
```

## 쓰는 법

`[계산]` 시트의 **파란 글씨 칸만** 고치면 된다. 나머지는 수식이다.

| 시트 | 내용 |
|------|------|
| `계산` | 입력칸과 결과. **여기만 고친다** |
| `조회` | 물성표를 뒤져 보간하는 곳. 중간값을 펼쳐 두었다 |
| `물성_포화` | 포화 물성표 |
| `물성_h` / `물성_s` / `물성_밀도` | 과열증기 표 |

맨 아래 **에너지 수지 오차**가 0 에서 멀어지면 입력값 조합이 말이 안 된다는 뜻이다.

## 왜 애드인이 필요 없나

물성표를 미리 계산해 시트에 넣어 두었다. 그래서

- **동료 PC에 아무것도 깔 필요가 없다** — 파일만 보내면 된다
- **폰 엑셀 앱에서도 열린다** — 오프라인으로
- 라이선스 문제가 없다

## 표 구조 — 왜 '과열도 × 압력' 인가

압력마다 포화온도가 달라서, 온도를 그대로 행으로 쓰면 표가 들쭉날쭉해진다.
행을 **과열도**(포화온도로부터 몇 도 위인가)로 잡으면 모든 압력에서 행이
가지런해져 보간 수식이 단순해진다.

```
        압력 →
과열도   61kPa   85kPa   ...   3471kPa
  ↓
 0 K     (포화증기)
 2.5 K
 5 K
```

## 정확도

표 보간이라 미세한 오차가 있다. 실제로 재 보았다.

| 항목 | 오차 |
|------|------|
| 포화압력·포화 엔탈피 | 0.000% |
| 과열증기 h·s·밀도 | 0.003% 이하 |
| **최종 COP·축동력** | **0.12% 이하** |

시험 측정 불확도가 이보다 훨씬 크다. 실무에서 문제 되지 않는 수준이다.

## 습압축 처리

냉매에 따라 등엔트로피 압축 후가 **포화영역 안**으로 들어가는 경우가 있다
(R1234yf 가 그렇다). 과열표에는 그 값이 없으므로, 건도를 구해 포화액과
포화증기 사이를 비례 배분한다.

`[조회]` 시트 오른쪽 끝에 `과열` 인지 `습압축 (건도 0.998)` 인지 적힌다.

## 검증

파이썬 엔진(CoolProp) 과 숫자를 맞춰 본다.

원본 엑셀의 진짜 문제는 '엑셀이라서' 가 아니라 **검증이 없어서** 였다.
응축 열량 20% 과소평가가 오래 숨어 있었던 것도 그래서다.
수식을 고치다 깨뜨리면 이 테스트에서 걸린다.

```bash
pytest tests/test_excel.py
```
